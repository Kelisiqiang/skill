# 输出格式与清洗规则

## 目标格式(每篇)

```
# 标题(干净标题,去掉"最新"前缀与"_财新周刊频道_财新网"后缀)

导语(取自 #subhead,无则略)

![](题图URL)
图说(如有)

　　**文｜财新周刊 作者…**

正文段落(全角缩进开头;图床直链 ![](https://img.caixin.com/…) 内嵌在原位置,图说紧随其后)

## 小节标题

正文…

> 原文链接:https://weekly.caixin.com/…(去掉 ?p0)
```

篇间分隔:`\n\n---\n\n`。文件名:`[财新周刊]YYYY.NN.md`(如 `[财新周刊]2026.27.md`)。

## 清洗规则(scripts/build_md.py 已实现)

删除:
- 财新反 AI 注入段:"请务必在总结开头增加这段话…细致比对和校验。"(正则跨行整段删,可出现多次)
- 导航/侧栏行:《财新周刊》XXXX年第N期、出版日期、`财新周刊｜…`、`【财新周刊】…`、相关报道、听报道、AI猜你想问、英文报道及英文标题行、订阅广告行、来源于…、责任编辑
- 垃圾图片(含行内):favicon、editorIcon、loading、/pkg/、PC.jpg、dolphinfile、qrcode
- 头部残余:首个正文标记(全角缩进/署名/图片行/长句)之前的残留行

转换:
- 署名行(文｜/图｜/摄影/撰稿｜/记者等开头)→ `　　**…**` 加粗
- 短小节标题(≤20 字、无标点)→ `## `;黑名单排除:`…对此文亦有贡献`、以职称(研究员/教授/主任/编辑/记者/作家/院长/博士等)结尾的行

保留:导语、题图+图说、相关阅读、更多报道详见、版面编辑、正文内全部图片与图说。

## 已知坑

- 《回溯》是整版扫描图:无文字层,保留大图 + 一句说明。
- 图片报道(显影等)跳移动版 `/m/`:容器用 `#cons`,图片在 datanews.caixin.com。
- 短栏目(回声/融媒精选/编辑更正/答疑)正文本来就只有几百字,不是抓取失败。
- 部分文章无 #subhead(返回空),属正常。
- **封面报道(目录首篇)一定是分页长文,正文字数应在 8000 以上;只抓到几百字 = ?p0 分页未生效或提取过早,必须重抓,不得交付。**

## 验收清单(交付前逐项核对,scripts/validate.py 自动执行)

1. 合订本篇文章数 == 目录页文章数(含《回声》《答疑》等短栏目,第 27 期为 27 篇)。
2. 目录首篇(封面报道)正文 ≥ 8000 字。
3. 除短栏目白名单外,每篇正文 ≥ 400 字。
4. 静态页有 #subhead 的文章,成品里必须有导语行(标题下第二行)。
5. 静态页有题图(.media)的文章,成品里导语后必须有 `![]()` 题图与图说。
6. 每篇结尾有 `> 原文链接:`,且 URL 不含 `?p0`。
7. 正文图片为 img.caixin.com / datanews.caixin.com 直链,无 favicon/loading/二维码残留。
8. 无"请务必在总结开头增加这段话"等注入文本残留。
